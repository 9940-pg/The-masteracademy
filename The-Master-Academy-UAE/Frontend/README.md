# ذا ماستر أكاديمي الإمارات — Frontend (UAE Edition)

الواجهة الأمامية لموقع **ذا ماستر أكاديمي الإمارات (The Master Academy UAE)**، مبنية باستخدام React 19 و Vite مع دعم كامل للغة العربية (RTL) وتصميم عصري متجاوب.

---

## 🇦🇪 المميزات الخاصة بنسخة الإمارات

- **اللغة**: اللغة العربية الفصحى بالكامل مع خط `Cairo` العصري من Google Fonts.
- **التصميم والاتجاه**: دعم كامل لليمين إلى اليسار (RTL - Right to Left).
- **العملة**: الدرهم الإماراتي (AED / د.إ) لجميع الدورات والبرامج التدريبية.
- **التوقيت**: توقيت الخليج الرسمي (GST - Gulf Standard Time / دبي وأبوظبي).
- **التواصل**: أرقام وقنوات واتساب مهيأة بدولة الإمارات (+971).
- **المنفذ (Port)**: يعمل على المنفذ `5174` عبر Vite حتى لا يتعارض مع النسخة الرئيسية على المنفذ `5173`.
- **الربط مع السيرفر**: متصل بسيرفر الإمارات عبر البروكسي الداخلي إلى `http://localhost:5001`.

---

## 🛠️ التشغيل السريع

### 1. تثبيت الحزم
```bash
npm install
```

### 2. تشغيل السيرفر المحلي
```bash
npm run dev
```

افتح المتصفح على: **`http://localhost:5174`**

### 3. بناء النسخة الإنتاجية
```bash
npm run build
```
