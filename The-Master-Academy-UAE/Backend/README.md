# ذا ماستر أكاديمي الإمارات — Backend API (UAE Edition)

REST API مبني باستخدام Node.js و Express لـ **ذا ماستر أكاديمي الإمارات (The Master Academy UAE)**، متصل بقاعدة بيانات MySQL لدولة الإمارات باللغة العربية والدرهم الإماراتي (AED).

---

## 🚀 المواصفات والمميزات

- **المنفذ (Port)**: `5001` (يعمل بشكل مستقل وبدون أي تعارض مع السيرفر الرئيسي على منفذ 5000).
- **قاعدة البيانات**: `master_academy_uae` في MySQL.
- **العملة**: الدرهم الإماراتي (AED / د.إ).
- **المنطقة والتوقيت**: الإمارات العربية المتحدة — دبي (توقيت الخليج الرسمي GST - UTC+4).
- **الجداول المهيأة**:
  - `contacts` — طلبات واستفسارات المتدربين في الإمارات.
  - `courses` — كتالوج الدورات والبرامج باللغة العربية والأسعار بالدرهم الإماراتي.
  - `enrollments` — تسجيلات الطلاب وتأكيد المقاعد.
  - `subscribers` — المشتركون في النشرة البريدية.
- **تهيئة وبذر تلقائي**: يقوم السيرفر بإنشاء قاعدة البيانات `master_academy_uae` والجداول وبذر الدورات الست تلقائياً عند التشغيل.

---

## 🛠️ التشغيل السريع

### 1. تثبيت الحزم
```bash
npm install
```

### 2. تشغيل السيرفر في وضع التطوير
```bash
npm run dev
```

يعمل السيرفر على الرابط: **`http://localhost:5001`**

## 📡 أهم نقاط الاتصال (API Endpoints)

| المسار | الطريقة | الوصف |
|---|---|---|
| `GET /api/health` | GET | فحص حالة السيرفر وقاعدة بيانات MySQL الإمارات |
| `GET /api/courses` | GET | جلب قائمة الدورات والأسعار بالدرهم الإماراتي |
| `GET /api/courses/:id` | GET | تفاصيل دورة محددة والمنهج الكامل |
| `POST /api/contact` | POST | استقبال استفسارات المتدربين وتخزينها في MySQL |
| `POST /api/enrollments`| POST | تسجيل متدرب في دورة |
| `POST /api/newsletter` | POST | اشتراك في النشرة البريدية |
